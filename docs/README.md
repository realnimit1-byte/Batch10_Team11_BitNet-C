# BitNet-C — Technical Documentation

This directory contains the official technical project report for **BitNet-C v2.4 — A Bitwise Optimized Binary Neural Network for Ultra Low Memory Activation**, developed by **Team Amateurs (Team 11, Batch 10)** for the First-Year B.Tech C Programming Mini Hackathon at UPES, Dehradun.

The report covers system architecture, binary neural-network inference, bitwise optimization, training methodology, memory analysis, testing, technical implementation, and individual team contributions.
